# Advanced Analytics Big Data: Course Portfolio

## Project Overview
The repository contains a portfolio of projects developed as a **collaborative group effort** for the "Advanced Analytics in a Big Data World" course. It explores modern data science, predictive modeling and computer vision, generative AI and complex graph theory.
 
## Methodology
* **Assignment 1:** Forecasted customer purchasing behavior and Customer Lifetime Value using a two-stage modeling approach to address zero-inflated distributions. Implemented and evaluated tree-based models including XGBoost, LightGBM, and CatBoost
* **Assignment 2:** used computer vision and transfer learning to predict categories of Lego minifigures
* **Assignment 3:** designed a RAG pipeline connected to a real database entries to recommend Steam games. Built a vector database for semantic search and integrated a local LLM for natural language generation

## Tools
* **Language:** Python, Cypher
**Machine Learning & CV:** `xgboost`, `lightgbm`, `catboost`, `scikit-learn`, OpenCV, MobileNetV2
* **GenAI & NLP:** ChromaDB (Vector DB), Ollama (phi3.5), Retrieval-Augmented Generation (RAG)
* **Graph & Web:** Memgraph, Gephi, Flask
   
## Repository Contents
* `Assignment1 Customer CLV.ipynb`: EDA and predictive modeling scripts for Customer Lifetime Value
* `Assignment2 Lego Classification.ipynb`: Computer vision and transfer learning notebooks
* `recommender.py`, `steam_sqlite.py`, `build_db.py`: Flask web app, vector database builder and RAG pipeline scripts
